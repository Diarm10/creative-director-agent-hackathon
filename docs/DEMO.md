# Three minute demo

This is the exact script for a short video of every feature, using the **Demo set** on the Catalogue tab. It uses the live site: https://creative-director-agent.vercel.app

The sample images in this repository are drawn illustrations, not photographs, so the photo check will not behave exactly as described below (for example the flask may not be held back). For a recording, use real product photos or the live site.

The demo code is given in the submission text. Do not show it on screen: type it in before you start recording.

## Before you record

Making an ad takes about 2 minutes, so a live run cannot fit in 3 minutes. Do this once, off camera, then record and cut:

1. Open the site, type the demo code (top right), open the **Catalogue** tab and click **Demo set**.
2. Wait for the photo checks to finish (about 20 seconds). You should see eight cards.
3. Check that **steel flask** is under **Held back**. The photo check is a model call and passes the flask about half the time. If the flask is not held back, click **Demo set** again to check it again.
4. Click **Make ads for the ready products** and let it finish (about 4 to 6 minutes for the five ads, four at a time). Do not approve anything yet. Leave the tab open; this is your finished set to record against.

Record the steps below on that finished page. Cut the waiting where marked.

## The script

| Time | Do | Say |
|---|---|---|
| 0:00 | Show the Catalogue tab with the finished Demo set. | "A small catalogue of eight photos. The agent checks each photo, then makes an ad for each product." |
| 0:10 | Point at the groups: **Ready** or **Check these** for five ads, **Held back** for the flask, the collection photo and the hand. | "Photos with a problem are held back with a plain reason. Nothing runs on them by itself." |
| 0:25 | Open one ad card (the mug). Show the original beside the ad, the score and the biggest problem. | "Each ad is scored by a critic on six parts, and the biggest problem is named." |
| 0:40 | Read the headline and subline. Click **Show other lines**, pick one. | "The words come from a copy engine. A subline is a benefit or an occasion, never a description of the photo, and it is left empty rather than filled with filler. Openings are not repeated across the batch." |
| 0:55 | Edit the headline, click **Apply text**. | "Editing words redraws at once. No model call." |
| 1:05 | In **Look, Theme and Effect**, choose **Magazine Cover**, then click **Redraw finished ads with this Look** (or use the Look dropdown on one card). Show a Magazine Cover ad with the big shop name across the top. | "A Look changes the layout. This one is a magazine cover: the shop name is the masthead and the product overlaps it." |
| 1:25 | Choose a Theme (Christmas), then the effect **Duotone** and click **Effect for all ads**. Show the count of skipped ads in the message. | "An effect redraws every finished ad in seconds, four at a time, and the page says how long it took. Ads that use the whole photo are skipped and counted, because effects apply to cut-out ads only." |
| 1:50 | On the **steel flask** card, click **Try anyway**. (Cut here; it takes about 2 minutes. Come back to the finished ad.) | "A held-back photo can be tried anyway. The product is cut out by name and must pass the same check." |
| 2:10 | On **busy-background**, click **Find items in this photo**. (Cut the wait.) Show the new rows named "dropper bottle (from busy-background.jpg)" and "sunglass (from busy-background.jpg)". | "A collection photo becomes one row for each item. Each one is cut out and checked on its own." |
| 2:30 | Point at **pouch-in-hand**: refused. Click nothing. | "A photo with a person or a hand is refused for good, on the page and again on the server." |
| 2:40 | Click **Approve** on two ads, then **Download approved ads**. | "Nothing is approved until you click it. The download is the approved ads and a results file." |
| 2:55 | Show the page header. | "Muse Spark, Muse Image and SAM on Meta's API, with Muse Spark Open on Baseten. Thank you." |

## If something goes wrong

- **The flask passes the check and is not held back.** Click **Demo set** again. If it still passes, run it with the others and show **Try another effect** instead.
- **An ad scores under 8.** That is normal: most ads score 7. Show the biggest problem line and move on.
- **A step says the daily limit is reached.** Use a fresh browser session later, or ask for the limit to be raised for the recording.
- **A rescue ad takes longer than 2 minutes.** Cut the wait. Do not stop the run.
